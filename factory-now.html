How it is measured

  • From GitHub's search API, across every repository in the Bygmedai organisation, private ones included.
  • Default branches only, so every figure is a lower bound: work that has not been merged is not counted.
  • Every morning, by a scheduled workflow. A change is proposed as a pull request and reaches this page when it is merged, so a measurement appears here only after review.
  • Every measurement is a commit to scripts/metrics.json in this site's public repository. Check every one, or read the script that measures and the workflow that runs it.
  • Client-facing solutions are counted by hand. What counts as one is a judgement, not a query.
  • Nothing is smoothed. The chart draws only what was measured. Where no measurement was taken for more than four days, the line is dashed and the gap is named.
